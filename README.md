# Commerce Platform – Microservices

## Overview

An educational E-Commerce platform built using Python and Microservices Architecture.

The project focuses on understanding and implementing distributed systems concepts through practical engineering decisions.

## Core Business Capabilities

- Authentication and Authorization
- Product Catalog
- Inventory Management
- Order Management
- Payment Processing (Simulation)
- Notifications

## Engineering Goals

The project aims to demonstrate:

- Understanding why and when Microservices Architecture is appropriate.
- Identifying Bounded Contexts and defining service boundaries.
- Implementing Distributed Transactions using the Saga Pattern.
- Preventing duplicate message processing through Idempotency.
- Handling service failures and communication errors.
- Implementing reliable asynchronous messaging.
- Testing individual services and the complete distributed workflow.

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- RabbitMQ
- Docker
- Pytest
